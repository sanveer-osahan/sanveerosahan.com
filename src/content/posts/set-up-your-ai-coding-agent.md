You open [ChatGPT](https://chatgpt.com) or [Claude](https://claude.ai) and ask it to do something for you.

Maybe you ask it to write a function. It writes a good one. You copy the code out, paste it into your editor, and hit run. Something breaks, so you copy the error back into the chat. It apologizes, hands you a fix, and you copy that one out too.

Or maybe you're pulling the same three fields out of thirty invoices into one spreadsheet. You ask it for a faster way. It explains the steps, or writes you a formula. You still open each file and key it in yourself, thirty times over.

If you've done either, you know the loop. For a while it felt like magic. Maybe it still does, and maybe you still work this way.

There's a lot you can do past that text box.

## What a coding agent changes

A coding agent closes that gap. It can reach into your workspace and do the work itself. You ask in plain words, same as always, and it handles the rest.
